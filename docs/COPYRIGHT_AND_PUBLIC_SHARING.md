# Copyright And Public Sharing Notes

This is not legal advice. It is a practical risk checklist for publishing this repository.

## Current Risk

Publishing fan-made pet sprites that visibly evoke an existing commercial anime character can create copyright, trademark, publicity, and platform-policy risk, even when:

- the assets are redrawn or AI-assisted rather than direct screenshots;
- the repository is non-commercial;
- the README says the project is unofficial;
- the package uses a renamed character or variant title.

The safest public release is one that avoids official artwork, screenshots, names, logos, title marks, and highly distinctive costume/character identifiers. A disclaimer helps with clarity but does not grant permission.

## What This Repository Does To Reduce Risk

- Uses a neutral public package name: `thorny-daily-v1`.
- Excludes official screenshots, reference captures, and source prompts from the public package.
- Keeps the included assets as small Codex pet sprites rather than full-resolution art.
- Does not include a permissive asset license by default.

## What Still Remains Risky

- The visual design may still be recognizable as fan art inspired by a protected character.
- A public GitHub repository is distribution, not just private use.
- Public GitHub repositories also permit viewing and forking through GitHub's service, so you need rights broad enough for that platform behavior.
- If the repo name, README, tags, or package IDs use official character or series names as branding, trademark/confusion risk increases.
- GitHub can receive and process copyright takedown notices under its DMCA policy.

## Recommended Before Making The Repo Public

1. Keep the repo name neutral, for example `codex-pet-wardrobe-pack`.
2. Do not use official series or character names in the repo name, package IDs, or marketing copy.
3. Do not include official screenshots, extracted frames, logos, music, episode stills, manga panels, or reference images.
4. Do not add MIT/Apache/CC0 licensing for the sprite assets unless the design has been made substantially original.
5. Use a restrictive notice such as: "No license is granted for the artwork assets. Personal, non-commercial use only."
6. If you want broad public reuse, redesign the pet into an original character first.
7. Be ready to remove or private the repository if a rights holder objects.
